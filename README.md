# 🐾 Dovelopers - Pet Care Center Management App

## 📝 프로젝트 소개

Dovelopers는 반려동물 돌봄 센터와 보호자를 연결하는 모바일 애플리케이션입니다. 실시간 모니터링, 일지 관리, 예약 시스템을 통해 더 나은 반려동물 케어 서비스를 제공합니다.

### 핵심 가치

- 💝 신뢰할 수 있는 반려동물 케어 서비스
- 🤝 보호자와 센터 간의 원활한 소통
- 📊 체계적인 반려동물 건강 관리

## ⭐️ 주요 기능

### 보호자용

- 실시간 반려동물 상태 모니터링
- 돌봄 센터 검색 및 예약
- 반려동물 프로필 관리
- 케어 히스토리 확인

### 센터용

- 📝 데일리 케어 일지 작성
- 📸 실시간 사진/영상 공유
- 📊 반려동물 건강 상태 기록
- 📅 예약 관리 시스템

## 🛠 기술 스택

### Frontend

- **Framework:** React Native, Expo
- **Language:** TypeScript
- **State Management:** Zustand
- **Styling:** TailwindCSS
- **API Client:** Axios

### Cloud

- **Authentication:** Firebase Auth

## 🚀 시작하기

### 필수 설치 항목

- Node.js (v16.0.0 이상)
- npm 또는 yarn
- Expo CLI
- iOS 시뮬레이터 또는 Android 에뮬레이터 (ios 권장)

### 설치 방법

```bash
# 저장소 클론
git clone https://github.com/gpbl-doveloper/front.git

# 프로젝트 디렉토리로 이동
cd front

# 의존성 설치
npm install

# 개발 서버 실행
npm start
# 또는
npx expo start
```

## 📱 환경 설정

### 환경 변수 설정

1. `.env.example` 파일을 `.env`로 복사
2. 필요한 환경 변수 값 입력

```
FIREBASE_API_KEY=your_api_key
FIREBASE_AUTH_DOMAIN=your_auth_domain
...
```
